Help & Support

Simple guidance to help you use the system without confusion

Getting Started

  1. Create your account as a Patient or Doctor
  2. Login using your registered credentials
  3. Access your personalized dashboard
  4. Start booking or managing appointments

Using the System

Patients: Book appointments, view prescriptions, and track medical history.

Doctors: Manage appointments, review patient records, and provide prescriptions.

Admin: Manage users, monitor activity, and control the system.

Common Issues

  • Login not working → check username and password
  • Appointments not visible → refresh or login again
  • Slow loading → check internet connection

FAQs

Can I cancel an appointment?
Yes, directly from your dashboard.

Yes, the system uses role-based secure access.

Can I book multiple appointments?
Yes, you can.
